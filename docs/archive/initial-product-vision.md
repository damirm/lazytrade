# lazytrade

Бот для автоматической торговли на биржах:
  - t-invest
    - документация: https://developer.tbank.ru/invest/intro/intro/
    - api: https://opensource.tbank.ru/invest/invest-contracts/-/tree/master/src/docs/contracts

В будущем добавятся crypto биржи:
  - bybit
  - kraken
  - okx
  - htx
  - kucoin
  - bingx
  - bitfinex

# Команды

`lazytrade agent` - запускает торговлю в терминале на основе описанных в конфиге стратегий
`lazytrade terminal` - запускает терминал в консоли, весь ui конфигурируется в конфигурационном файле, какие должны быть табы, с какой биржей, какие инструменты отображать и т.д.

Это должен быть один бинарный файл, но с подкоммандами внутри.

# Агент

Агент торгует согласно описанному конфигу. В конфиге можно описать разные стратегии торговли. Один агент параллельно может торговать на разных биржах, разными инструментами и разными стратегиями.

Агент отписывает в output / log все выполненные транзакции и собирает статистику торговли (сколько заработал / сколько потерял и т.д.).

Агент запускает web интерфейс, в котором в real-time обновляется статистика торговли, и есть возможность приостановить торговлю per биржа / инструмент / стратегия.

# Терминал

Терминал выполняет read-only функцию, позволяет наблюдать за текущим состоянием биржи. По каждому инструменту отображается real-time график с разными режимами.

# Технологии

Бот реализован на языке golang.

Для tui используются:
- github.com/charmbracelet/bubbletea
- github.com/charmbracelet/bubbles
- github.com/charmbracelet/lipgloss

Для рисования графиков в терминале используется пакет github.com/guptarohit/asciigraph

Конфиг описывается в формате yaml. Для агента и terminal можно использовать один и тот же файл конфига, но в нем должны быть отдельные секции.

Для хранения состояния используется sqlite.

Для работы с sql используется пакет github.com/sqlc-dev/sqlc
