# Вспомогательные AI-материалы

Каталог `.ai/` не является канонической базой знаний lazytrade.

Канонические проектные документы находятся в `docs/`, а обязательная точка
входа для агентов — корневой `AGENTS.md`.

В `.ai/` допускаются только:

- `references/` — локальные копии внешней документации и upstream contracts;
- `drafts/` — ещё не принятые исследовательские черновики;
- `generated/` — временные машинно созданные материалы.

Сейчас `.ai/references/tinvest/invest-contracts/` содержит snapshot внешней
документации T-Invest. Он служит первичным источником API-контрактов, но наши
решения на его основе должны фиксироваться в `docs/architecture/adr/`,
`docs/specs/` или тематической документации.

Не помещать сюда единственную копию принятого решения. Если черновик принят,
перенести выводы в `docs/` и удалить либо явно пометить черновик устаревшим.
